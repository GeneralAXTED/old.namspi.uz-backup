# old.namspi.uz

> Archive of the old **namspi.uz** website frontend.

## 📖 About

This repository contains a downloaded copy of the **old frontend** of the official **Namangan State Pedagogical Institute (NamSPI)** website (**namspi.uz**).

The purpose of this repository is to preserve the previous website interface for:

- Historical reference
- UI/UX comparison
- Educational purposes
- Frontend development research
- Design inspiration and migration

> **Note:** This repository only includes the frontend files that were downloaded from the publicly accessible website. It does **not** contain the original backend source code, database, CMS, or server-side functionality.

---

## 📂 Contents

- HTML pages
- CSS stylesheets
- JavaScript files
- Images
- Fonts
- Other static assets

---

## ⚠️ Limitations

Since this is a downloaded version of the website:

- Dynamic pages may not function correctly.
- Forms are non-functional.
- Search features are unavailable.
- Backend APIs are not included.
- Database-driven content is static.
- Authentication and admin features are absent.

---

## 🎯 Purpose

This project is intended for:

- Website archival
- Frontend preservation
- Learning HTML/CSS/JavaScript
- UI redesign and modernization
- Migration to newer technologies

---

## 🚀 Running Locally

Simply clone the repository and open `index.html` (or the appropriate entry page) in your browser.

```bash
git clone https://github.com/GeneralAXTED/old.namspi.uz.git
cd old.namspi.uz
```

You can also serve the files using any local web server, for example:

```bash
python -m http.server
```

or

```bash
php -S localhost:8000
```
